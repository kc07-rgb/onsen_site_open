# onsen-site
温泉サイト
架空の温泉宿を想定して制作したWebサイトです。
宿泊予約やお問い合わせ、ユーザー登録・ログイン、管理者画面でのニュース投稿・編集機能を実装しました。

サイトURL
www.konsent.shop/onsen/index.php
管理者画面
www.konsent.shop/onsen/admin/dashboard.php

<使用言語>
HTML、CSS、JavaScript、PHP、MySQL

<機能>
予約機能
•宿泊プラン・人数・宿泊日数による料金計算
•予約内容の確認・確定
お問い合わせ機能
管理者画面
•ユーザー登録、ログイン機能
•ニュース投稿、編集機能

<学んだこと>
このサイトの制作を通して、HTML・CSS・JavaScriptだけでなく、PHPとMySQLを用いたデータベース連携や、ユーザー登録・ログインなどの基本的なWebアプリケーション開発の流れを学びました。
今後はデザインやUI/UXについても学び、より使いやすく見やすいWebサイトを制作できるよう取り組んでいきます。
